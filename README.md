# 뭐고이건 (what_the_pay)

카드 내역에 "NHN KCP", "다날"처럼 결제대행사 이름만 떠서 **무엇을 산 건지 바로 알 수 없는 불편**을 줄이기 위한 웹페이지입니다.

> 현재 상태: **첫 화면(시안)만 있습니다.** 저장 기능과 실시간 정보는 아직 연결되지 않았고, 화면의 숫자와 메모는 모두 예시 값입니다.

## 누구를 위한 서비스인가요

- 온라인 결제를 자주 하는 사람
- 카드 내역이나 결제 문자를 보고 지출을 확인하는 사람

## 지금은 어떻게 버티나요

금액과 날짜를 보고 기억을 더듬거나, 메일함과 앱을 하나씩 뒤져서 찾습니다. 못 찾으면 그냥 넘어갑니다.

## 이 페이지가 해 주는 한 가지

결제 내역(결제처 이름, 금액, 날짜)을 입력하고 "이건 넷플릭스"처럼 메모를 **한 번만** 달아 두면, 다음에 **같은 결제처와 같은 금액**이 들어왔을 때 그 메모를 자동으로 보여 줍니다.

## 필요한 기능

| 기능 | 내용 | 상태 |
| --- | --- | --- |
| 저장 | 결제처 이름 + 금액 → 내가 단 메모 목록 | 나중에 연결 |
| 메모별 합계 | 메모별 이번 달 합계 | 나중에 연결 |

## 화면 구성

- 상단 바: 서비스 이름과 "메모 달아 보기" 버튼
- 입력 카드: 결제처 이름, 금액, 날짜, 내 메모
- 예시 카드 2장: 같은 결제가 들어왔을 때 메모가 보이는 모습, 메모 목록과 이번 달 합계 자리

## 실행 방법

별도 설치가 필요 없습니다. `payment-memo-landing.html` 파일을 웹 브라우저로 열면 됩니다. 휴대폰 화면에도 맞게 만들었습니다.
